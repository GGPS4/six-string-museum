# The Six-String Museum

A museum for guitars that runs entirely in the browser. Every sound is synthesized live with a plucked-string (Karplus–Strong) model and the Web Audio API. There are no samples, no build tools and no dependencies.

**Live site:** https://ggps4.github.io/six-string-museum/

## Wings

| Wing | What it does |
| --- | --- |
| A · Hall of Fame & Graveyard | Donate a guitar with its story, scars and most-played songs. Sold, broken, lost and stolen guitars rest in the Graveyard. |
| B · Luthier Workshop | Choose a body, wood, fretboard, pickups and finish, then hear how each choice changes the sound. |
| C · Riff Roulette | A slot machine picks a key, tempo, mood and house rule. Write a riff in tab, play it back and post it to the wall. |
| D · Pedalboard Playground | Chain eight invented pedals into an amp. Drag to reorder, bypass with footswitches, load presets and share rigs. |
| E · Tone Detective | Hear a mystery tone and guess the rig that made it. |
| F · Guitar Teacher | 50 short guitar theory lessons in five units, each with playable examples and a quiz question. |
| G · Chord Shape Tarot | Draw three chord cards, play the reading as a progression and find out which key it's in. |
| H · Wood Library | Eleven tonewoods with density, origin and uses, plus a blind A/B listening test. |
| I · Fretboard Speedrun | Find 20 notes against the clock, on one string or all six, with a leaderboard. |
| J · Guitar Family Tree | From the oud to the seven-string. Click any instrument to trace its line of descent. |
| K · Broken Neck Hospital | Diagnose and treat sick guitars from their symptoms, several of which you can hear. |

## Files

- `index.html` is the page that GitHub Pages serves. It is generated by `build.sh`.
- `page.html` holds the page markup and styles. The Claude artifact version uses it directly.
- `app.js` has the sound engine, guitar drawing, data layer and wings A–E.
- `wings.js` has wings F–K.
- `lessons.js` holds the 50 Guitar Teacher lessons.

Edit `page.html`, then run `./build.sh` to regenerate `index.html`.

## Saved data

On GitHub Pages, donated guitars, riffs, rigs, scores and lesson progress are saved in your own browser (localStorage). When the same page runs as a Claude artifact, the walls and leaderboard are shared by everyone who visits.

Pedal names and guitar builds are invented. The Family Tree names real historical instruments, and its dates are approximate.
